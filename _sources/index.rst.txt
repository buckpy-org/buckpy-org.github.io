BuckPy (Probabilistic Lateral Buckling Algorithm)
#################################################

******************
Project Philosophy
****************** 
  **BuckPy** is an open-source algorithm that has been developed to facilitate the implementation
  of the probabilistic lateral buckling methodology presented in
  :download:`SPT 2023: Lateral Buckling Design using the Friction Distributions at the Expected Buckles <_static/SPT 2023 - Lateral Buckling Design using the Friction Distributions at the Expected Buckles.pdf>`
  published by Ismael Ripoll, Carlos Sicilia and Emilien Bonnet at the 2023 Subsea Pipeline Technology Congress in London (SPT 2023).
  
  
  
  The code is available in `GitHub <https://github.com/Xodus-Group/BuckPy>`_
  with the intend of allowing the pipeline community to review, expand, and use it under a
  `GNU General Public License v3.0 <https://github.com/Xodus-Group/BuckPy/blob/main/LICENSE>`_.

********************************
How to Contribute to the Project
********************************
  Interested in contributing to the project?
  
  - The code repository is private. Please contact any of the project team members to get access.

  Once you have access to the repository, you can contribute in the following ways:

  - If you have a contribution in mind, please add in `Discussions <https://github.com/Xodus-Group/BuckPy/discussions>`_.
  - If you have identified an issue with the code, please add in `Issues <https://github.com/Xodus-Group/BuckPy/issues>`_.
  - If you want to contribute code, please create a `Pull Request <https://github.com/Xodus-Group/BuckPy/pulls>`_.

  Interested in trying out the code before contributing?

  - Please refer to <https://pypi.org/project/buckpy/> and the `Getting Started <getting_started.html>`_ section of this documentation.
